MHUR FRANCE — CORRECTIF V550
================================

CE CORRECTIF REMPLACE LE V549
=============================

Le V549 remplaçait le fond complet du bouton du tutoriel par une image
radiale et supprimait des éléments selon leur taille. Il est retiré.

CORRECTIONS
===========

1. TUTORIEL MODS
   - fond orange / jaune original restauré ;
   - texte et icône conservés ;
   - une seule flèche ronde à droite ;
   - seules les anciennes classes de flèche connues sont supprimées.

2. PATCH NOTES / DEV NOTES
   - les deux onglets sont forcés visibles ;
   - une ancienne fenêtre incomplète est supprimée puis reconstruite
     automatiquement par le système original ;
   - les clics Patch Notes et Dev Notes fonctionnent de nouveau.

3. DÉFILEMENT DES DEV NOTES
   - le panneau utilise Flex ;
   - le titre et les onglets restent en haut ;
   - la zone principale prend tout l'espace restant ;
   - le contenu peut défiler jusqu'au dernier bloc ;
   - une marge de sécurité est ajoutée en bas sur téléphone.

4. CONSERVÉ
   - V547 ;
   - V548 ;
   - les corrections des rôles, du profil, du mobile et des portraits.

INSTALLATION
============

1. Décompresse le ZIP.
2. Copie son contenu dans le dossier principal mhur-france.
3. Choisis "Remplacer les fichiers" si Windows le demande.
4. Lance :
   APPLIQUER_CORRECTIF_V550.bat
5. Attends :
   TOUTES LES VERIFICATIONS V550 SONT BONNES
6. Dans GitHub Desktop :
   Commit to main
   Push origin
7. Sur ordinateur :
   Ctrl + F5
8. Sur téléphone :
   ferme complètement l'onglet,
   puis rouvre le site.

Aucun SQL Supabase n'est nécessaire.
Ne relance pas le V549 après le V550.
