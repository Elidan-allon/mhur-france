le fonctionnement du site.

- refuse de continuer si index.html contient un conflit Git ;
- vérifie que tous les JS/CSS chargés par index.html existent ;
- crée une archive horodatée ;
- déplace les anciens installateurs, payloads et sauvegardes dans l'archive ;

  référencés par aucun fichier du site ;

- retire les commentaires « Season 18 compatibility layer » répétés ;
- vérifie encore le site après le nettoyage ;

1. Décompresse le ZIP à la racine de mhur-france.
2. Lance d'abord SIMULER_NETTOYAGE_V575.bat.

5. Vérifie RAPPORT_NETTOYAGE_V575.txt.
