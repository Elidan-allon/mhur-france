MHUR NEXUS — CORRECTIF SAISON 18 V24
====================================

Cette version automatise les badges NEW et sépare correctement le contenu à venir.

COSTUMES À VENIR
- Tous les costumes dont la date de sortie UltraRumble Database est dans le futur restent dans « Costumes à venir / Upcoming Costumes ».
- Ces costumes ne reçoivent pas le badge NEW avant leur sortie.

NOUVEAUX COSTUMES
- Le badge NEW est placé uniquement sur le lot de costumes ayant la date de sortie passée la plus récente.
- Quand un nouveau lot sort, le badge disparaît automatiquement de l'ancien lot et passe sur le nouveau.

NOUVEAU PERSONNAGE ET NOUVEAUX STYLES
- Le personnage sorti le plus récemment reçoit le badge NEW.
- Les styles sortis le plus récemment reçoivent aussi le badge NEW.
- Quand un autre personnage ou un autre lot de styles sort, les anciens badges sont retirés automatiquement.

MISE À JOUR
- Le script de synchronisation lit maintenant les dates de sortie des personnages, styles et costumes.
- Le cache des fichiers Saison 18 passe à la version 24000.

Installation :
1. Copier le dossier mhur-france sur le site actuel.
2. Accepter les remplacements.
3. Lancer METTRE_A_JOUR_MHUR_FRANCE.bat afin de récupérer les dates les plus récentes.
4. Redéployer public et faire une actualisation forcée une fois.
