INSTALLATION
============

1. Décompresse le ZIP.
2. Copie tout son contenu dans le dossier principal "mhur-france".
3. Accepte la fusion du dossier public.
4. Lance APPLIQUER_CORRECTIF_V522.bat.
5. Ouvre GitHub Desktop.
6. Message conseillé :
   Correctif V522 cartes personnages Gentle et fleche mods
7. Clique sur Commit to main.
8. Clique sur Push origin.
9. Après le déploiement, recharge le site avec Ctrl + F5.
