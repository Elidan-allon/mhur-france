INSTALLATION
============

1. Décompresse le ZIP.
2. Copie tout son contenu dans le dossier principal local « mhur-france ».
   APPLIQUER_CORRECTIF_V521.bat doit être au même niveau que le dossier public.
3. Accepte seulement la fusion des dossiers. Il est normal que Windows ne demande
   pas toujours de remplacer un fichier : les fichiers V521 sont nouveaux.
4. Double-clique sur APPLIQUER_CORRECTIF_V521.bat.
5. Dans GitHub Desktop, vérifie les changements.
6. Message conseillé : Correctif V521 interface personnages et rôles
7. Clique sur Commit to main, puis Push origin.
8. Après le déploiement, recharge le site avec Ctrl + F5.

Le programme retire automatiquement les balises et fichiers V519/V520.
Il crée aussi : public/index.html.avant-v521.bak

Pour enlever uniquement V521 sans remettre V519/V520 :
double-clique sur RETIRER_CORRECTIF_V521.bat.
