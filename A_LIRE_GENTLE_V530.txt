public/index.html actuel ne le charge pas.

INSTALLATION
============

1. Decompresse le ZIP dans le dossier principal mhur-france.
2. Lance APPLIQUER_GENTLE_V530.bat.
3. La fenetre doit afficher :
   TOUTES LES VERIFICATIONS V530 SONT BONNES
4. Dans GitHub Desktop :
   Commit to main
   Push origin
5. Apres le deploiement :
   Ctrl + F5
