MHUR NEXUS V5.1 — CORRECTION MODÉRATION + AFFICHAGE RESPONSIVE

ÉTAPES OBLIGATOIRES

1. Publier le contenu du dossier public/ sur Cloudflare.
2. Ouvrir Supabase > SQL Editor.
3. Exécuter entièrement :
   configuration/A_EXECUTER_DANS_SUPABASE_V51.sql
4. Attendre quelques secondes puis tester avec un compte membre.

CORRECTIONS

- Le bouton de modération d'un profil ouvre désormais toujours le nouveau panneau V5.1.
- Les avertissements, bans temporaires et bans définitifs reçoivent automatiquement un identifiant de sanction.
- Le message à la modération n'affiche plus « sanction à actualiser ».
- Le recours est créé côté serveur, même pour une ancienne sanction sans sanction_id.
- Un seul message reste autorisé par sanction.
- Le ban temporaire affiche la page rouge et le compte à rebours sans bloquer le JavaScript.
- Le ban définitif affiche la page rouge et ne laisse que le bouton de recours.
- L'ancien écran de ban V3.5 est neutralisé pour éviter le gel ou la page vide.
- Un déban ou la fin du compteur déverrouille automatiquement le site.
- L'en-tête se compacte automatiquement selon la largeur et le zoom du navigateur.
- Si l'espace devient insuffisant, les libellés deviennent des icônes puis le logo central se masque plutôt que de chevaucher les boutons.

TEST RAPIDE

- Avertissement : la page s'affiche, « J'ai compris » fonctionne et le recours part.
- Ban temporaire : la page rouge reste affichée, le compteur descend et le recours part.
- Ban définitif : la page rouge reste affichée et seul le recours est utilisable.
- Réduire la fenêtre et tester un zoom navigateur élevé : aucun bouton du header ne doit recouvrir le logo ou un autre bouton.
