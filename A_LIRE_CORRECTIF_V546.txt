INSTALLATION
============

1. Décompresse le ZIP.
2. Copie son contenu dans le dossier principal mhur-france.
3. Lance :
   APPLIQUER_CORRECTIF_V546.bat
4. Attends :
   TOUTES LES VERIFICATIONS V546 SONT BONNES
5. Dans GitHub Desktop :
   Commit to main
   Push origin
6. Sur ordinateur :
   Ctrl + F5
7. Sur téléphone :
   ferme complètement l'onglet,
   rouvre le site,
   puis actualise une fois.

Aucun SQL Supabase n'est nécessaire.
Ne relance pas V545 après V546.
