CORRECTIF VERROU WINDOWS
========================

Ce correctif remplace la détection de processus Windows qui utilisait os.kill(pid, 0)
et pouvait provoquer :
  SystemError / WinError 87 / The parameter is incorrect

Le fichier synchronisation_en_cours.lock est maintenant :
- conservé si une vraie mise à jour est encore en cours ;
- supprimé automatiquement si le processus est terminé ;
- supprimé automatiquement s'il est vide, invalide ou trop ancien ;
- géré sans faire planter la mise à jour sous Windows.

Après avoir copié les fichiers, relance simplement METTRE_A_JOUR_MHUR_FRANCE.bat.
