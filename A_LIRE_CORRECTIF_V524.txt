INSTALLATION
============

1. Décompresse le ZIP.
2. Copie tout dans le dossier principal "mhur-france".
3. Accepte la fusion du dossier public.
4. Lance APPLIQUER_CORRECTIF_V524.bat.
5. Dans GitHub Desktop :
   - Commit to main
   - Push origin
6. Attends le déploiement.
7. Recharge le site avec Ctrl + F5.
