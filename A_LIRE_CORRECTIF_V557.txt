MHUR FRANCE — CORRECTIF V557
================================

CORRECTIONS
===========

1. ORDRE DES TABLEAUX D'ALTERS

   Le tableau « Effets de montée » est toujours placé tout en haut,
   avant les valeurs de base et les valeurs supplémentaires.

   Cela fonctionne aussi lorsque le site est en anglais et que le titre
   devient « Level-up Effects ».

   Sont concernés :
   - Alter α ;
   - Alter β ;
   - Alter γ ;
   - Action spéciale.

2. TRADUCTION ANGLAISE COMPLÈTE DES TABLEAUX

   Le correctif retraduit les titres, colonnes, types et effets déjà
   affichés en français dans le mode anglais.

   Exemples :
   - Ruée -> Rush ;
   - Rebond -> Rebound ;
   - Impact final -> Final Impact ;
   - Niveau -> Level ;
   - Dégâts -> Damage ;
   - Munitions -> Ammo ;
   - Vitesse de rechargement -> Reload Speed ;
   - Taille -> Size ;
   - Effets de montée -> Level-up Effects.

3. CHANGEMENT DE LANGUE

   L'ordre et la traduction sont recalculés après :
   - un changement FR / EN ;
   - un changement de personnage ;
   - un changement de style ;
   - un nouveau rendu de la page.

4. CONSERVÉ

   Le V556 et tous les autres correctifs actifs restent chargés.
   Aucun fichier de données et aucun SQL Supabase ne sont modifiés.

INSTALLATION
============

1. Décompresse le ZIP.
2. Copie son contenu dans le dossier principal mhur-france.
3. Choisis « Remplacer les fichiers dans la destination » si demandé.
4. Lance :
   APPLIQUER_CORRECTIF_V557.bat
5. Attends :
   TOUTES LES VERIFICATIONS V557 SONT BONNES
6. Dans GitHub Desktop :
   Commit to main
   Push origin
7. Sur PC :
   Ctrl + F5
8. Sur téléphone :
   ferme complètement l'onglet puis rouvre le site.
