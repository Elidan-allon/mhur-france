INSTALLATION
============

1. Décompresse ce ZIP.
2. Copie tout son contenu dans le dossier principal "mhur-france".
   Tu dois voir les dossiers "public", "configuration", etc. au même niveau.
3. Lance APPLIQUER_CORRECTIF_V525.bat.
4. À la fin, la fenêtre doit écrire :
   "Toutes les vérifications V525 sont bonnes."
5. Si cette phrase n'apparaît pas, ne fais pas le Push.
6. Dans GitHub Desktop :
   - Commit to main
   - Push origin
7. Après le déploiement, recharge le site avec Ctrl + F5.
