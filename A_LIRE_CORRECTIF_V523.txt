MHUR FRANCE — CORRECTIF V523

   - La zone photo est carrée pour rester propre sur toutes les largeurs.

2. INTERFACE DES ALTERS

     l'ancienne photo depuis le cache.

   - Le JavaScript force aussi cette image après chaque affichage.

4. TUTORIEL DES MODS

   - Une seule flèche ronde reste à droite.

5. CONSERVÉ
   - Logos de rôle dans les réductions.
   - Couleurs des rôles dans les Builds communauté.
   - Texte blanc de la fiche personnage.


INSTALLATION
============

1. Décompresse le ZIP.
2. Copie tout le contenu dans le dossier principal "mhur-france".
3. Accepte la fusion du dossier public.
4. Lance APPLIQUER_CORRECTIF_V523.bat.
5. Dans GitHub Desktop :
   - Commit to main
   - Push origin
6. Attends le déploiement.
7. Recharge avec Ctrl + F5.
