MHUR FRANCE — CORRECTIF V526

CORRECTIONS
===========

1. FICHE PERSONNAGE
   Tous les textes de présentation redeviennent blancs :
   nom, style, description, rôle et titre Alter.

2. TAILLE DES CARTES
   Les sélecteurs Personnages, Costumes, T.U.N.I.N.G et

   - largeur : 280 px
   - hauteur : 680 px

   - largeur : 330 px
   - hauteur : 450 px
   - zone image : 330 px

   Les portraits sont affichés entièrement, centrés et sans
   les anciens déplacements ou agrandissements.

   Chaque carte reçoit le fond correspondant à son rôle :
   Assaut jaune, Attaque rouge, Vitesse cyan,
   Technique violet et Soutien vert.

4. GENTLE CRIMINAL
   Le ZIP contient réellement le fichier officiel :
   public/assets/gentle_criminal/gentle_criminal_technical/portrait.png

   Il est copié sous un nouveau nom :
   public/assets/home/discounts/gentle_criminal_correct_v526.png

   home_data.js est modifié directement et le JavaScript V526
   vérifie aussi l'image affichée. Le nouveau nom empêche le
   navigateur de réutiliser une ancienne image en cache.

INSTALLATION
============

1. Décompresse ce ZIP.
2. Copie tout dans le dossier principal "mhur-france".
3. Accepte la fusion du dossier public.
4. Lance APPLIQUER_CORRECTIF_V526.bat.
5. Attends le message :
   TOUTES LES VÉRIFICATIONS V526 SONT BONNES
6. Dans GitHub Desktop :
   Commit to main
   Push origin
7. Après le déploiement :
   Ctrl + F5

NE POUSSE PAS si la vérification affiche une erreur.
Prends une capture de la fenêtre noire dans ce cas.
