# Correctif MHUR France V560

Ce pack corrige uniquement les points demandés :

- badges NEW placés à droite sous la rareté ;
- NEW sur la tenue Originale de Gentle Criminal et les contenus actifs de la mise à jour ;
- badges INCOMING sur les contenus non encore sortis ;
- animation agrandir/rétrécir pour tous les NEW ;
- vrais portraits et vrais logos de rôles dans les réductions ;
- Factor Fusion corrigé vers All For One — Strike ;
- images exactes des compétences dans les patch notes ;
- tag de contexte T.U.N.I.N.G / CHARACTER / COSTUMES sur les cartes ;
- traductions anglaises des pages Mods et Builds ;
- flèche du tutoriel Mods réparée ;
- badge NEW de Gentle dans la tier list.

## Installation

1. Décompresser le ZIP.
2. Copier tout ce qu’il contient dans le dossier principal `mhur-france`.
3. Accepter le remplacement des fichiers si Windows le demande.
4. Lancer `APPLIQUER_CORRECTIF_V560.bat`.
5. Dans GitHub Desktop : `Commit to main`, puis `Push origin`.
6. Une fois le déploiement terminé, faire `Ctrl + F5` une seule fois.

Une sauvegarde de `public/index.html` est créée sous
`public/index.html.avant-v560.bak`.

Pour revenir en arrière, lancer `ANNULER_CORRECTIF_V560.bat`.
