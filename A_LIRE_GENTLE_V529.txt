GENTLE CRIMINAL - CORRECTIF V529
================================

LE V528 AVAIT UNE ERREUR DE SYNTAXE POWERSHELL.
CE FICHIER EST UNE NOUVELLE VERSION SIMPLIFIEE.

VRAIE CAUSE TROUVEE
===================

Le site possede plusieurs corrections qui se contredisent :

1. Le bloc V525 integre dans public/index.html force :
   portrait_v525.png?v=525

2. public/js/v526-ui-final.js est charge apres V525 et force :
   gentle_criminal_correct_v526.png?v=526

3. public/data/home_data.js utilise encore une autre image.

Remplacer uniquement gentle_criminal.webp ne pouvait donc pas fonctionner :
les observateurs JavaScript remettaient ensuite une ancienne image.

V529 fait pointer les TROIS endroits vers le seul fichier voulu :

public/assets/gentle_criminal/gentle_criminal_technical/portrait.png

INSTALLATION
============

1. Decompresse le ZIP.
2. Copie les fichiers dans le dossier principal mhur-france.
3. Lance APPLIQUER_GENTLE_V529.bat.
4. La fenetre doit afficher :
   TOUTES LES VERIFICATIONS V529 SONT BONNES
5. Dans GitHub Desktop, fais Commit to main puis Push origin.
6. Apres le deploiement, recharge avec Ctrl + F5.
